# ⭐ Своя Игра 6+ — APK для Android

Детская «Своя игра» для двух игроков: 3 выпуска × 8 категорий × 5 вопросов (120 вопросов),
очки, автоматическая смена хода, звуки, конфетти, сохранение прогресса.
Игра полностью офлайн. Требования: Android 7.0+ (API 24).

## Сборка

Вкладка **Actions** → workflow **Build APK** → дождаться зелёной галочки.
Готовый файл появится в **Releases** (`SvoyaIgra.apk`) и в **Artifacts** запуска.

Локально: Android Studio → Open → Build → Build App Bundle(s) / APK(s) → Build APK(s).

## Установка

Откройте `SvoyaIgra.apk` на телефоне → разрешите установку из неизвестных источников →
Установить. Предупреждение Play Protect нормально: приложение подписано debug-ключом.

## Управление

- Нажми на имя (✎) — переименовать игрока; на зверька — сменить аватар.
- «🔊 Звук» сверху выключает все звуки.
- «✨ Новая игра» обнуляет очки и открывает следующий выпуск с новыми вопросами.
- Выход — кнопка «Назад» дважды.

Вопросы редактируются в `app/src/main/assets/index.html` (массив `PACKS`).
